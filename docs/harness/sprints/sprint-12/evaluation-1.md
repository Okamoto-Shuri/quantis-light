## 改善提案（合格判定には影響しないが推奨）

- **件数の分母がそろっていない**:
  - ダッシュボードの銘柄数（14）と、取り込み状況の「銘柄マスタ 14 銘柄のうち」は、上場廃止を含む。
  - スクリーニングの「銘柄マスタ 13 銘柄中」は含まない。
  - 契約（「ほかの件数は変えない」）どおりで、「うち上場廃止 N 銘柄」も併記されている。ただ、将来は財務・判定のカバー率の分母を上場中にそろえるとよい。
- **応答の無い実行の「一部完了」に残りが出ない**: 残りを数えないため、実行履歴の行に残りが表示されない。「残りは次回の取り込みで処理します」の文言はあるので実害は小さいが、「残り 不明」と示すと一貫する。
- **R4 の確かめ方を再利用できる形にする**: ジェネレーターは行を足す方法を採ったため、件数の検査が落ちた。評価者の方法（`data_freshness` の既定の時刻を一時的にずらす）なら行を増やさずに境の後の状態を再現できる。CLAUDE.md の E2E の手順に書いておくと、次から検証しやすい。
- **大きい ID の扱い**: `/api/ingestion/runs/9223372036854775807`（bigint の最大値）は 400 `invalid_id` になる。実害は無い。

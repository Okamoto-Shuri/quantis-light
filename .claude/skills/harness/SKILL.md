# 3エージェント開発ハーネス

引数（ユーザーの1〜4行のプロンプト）: $ARGUMENTS

あなた（メインセッション）はオーケストレーターです。自分で実装やテストはせず、サブエージェントを順番に呼び出し、ファイル経由で成果物を受け渡します。サブエージェント同士は直接会話できないため、指示には必ず対象スプリント番号と参照ファイルのパスを含めてください。

## 成果物の置き場所

```
docs/harness/
  spec.md                     # planner が作成
  sprints/sprint-NN/
    contract.md               # generator が作成
    contract-review.md        # evaluator が作成
    self-review.md            # generator が作成
    evaluation-R.md           # evaluator が作成（R = ラウンド）
```

## 手順

1. **計画**: `planner` にユーザーのプロンプトをそのまま渡し、`docs/harness/spec.md` を作らせる。完了後、スプリント計画の要約をユーザーに提示し、進めてよいか確認する。

2. **スプリントループ**: スプリント N = 1 から順に:
   1. `generator` に「Sprint N の契約を作成」させる
   2. `evaluator` に「Sprint N の契約をレビュー」させる。修正依頼なら generator に更新させる（最大2往復）
   3. `generator` に「Sprint N を実装」させる
   4. `evaluator` に「Sprint N を評価（ラウンド R）」させる
   5. 不合格なら `generator` に「Sprint N のフィードバックに対応（evaluation-R.md を参照）」させ、4 に戻る
   6. 合格したら次のスプリントへ。各スプリント終了時にユーザーへ1〜2行で進捗を報告する

3. **打ち切り**: 同じスプリントで評価が5ラウンド不合格になった場合は、ループを止め、最新の評価レポートの要点をユーザーに伝えて判断を仰ぐ。

4. **完了**: 全スプリント合格後、構築したもの・起動方法・未解決の改善提案をまとめて報告する。
